# Xano, "Rebuild a SaaS Tool You Hate"

| | |
|---|---|
| Prize | 1,000 USD cash plus 500 credit, second place 500 plus 500 |
| Contact | cameron.b@xano.com |

## The challenge

Pick a business application you use today and build a better version with AI.
CRM, support desk, HR system, procurement portal, project management, or
something else entirely.

## The only requirement

Xano must be the backend in a meaningful way: business logic, APIs, workflows,
authentication, integrations or data model.

## Submit, and note the build story

Project name and one line pitch, public repository, two to four minute demo,
and a build story answering: what software did you replace, why did you choose
it, which AI tools did you use, roughly how long did it take, and what would
have taken significantly longer without AI and Xano.

The build story asks directly which AI tools were used. That sits against the
standing rule that the repository carries no tooling references. The rule holds
for code, comments and commit messages; the submission form is a separate
surface and needs an explicit decision.
