## Overall winner

12,500 USD in value. One winner. Judged on three things only:

| Criterion | The question asked |
|---|---|
| Progress | How much progress did you make? |
| Concept | Does it solve a real problem? |
| Feasibility | Could this become a startup or company? |

Sponsors pick their own track winners using their own criteria, independently
of the overall award.

## Submission shape, common to most tracks

Project name and a one line pitch, a public repository with setup
instructions, a two to four minute demo video showing the thing working end to
end, and one line naming where that sponsor's API did the real work.
